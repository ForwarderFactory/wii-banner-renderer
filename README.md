# wii-banner-renderer

[![Build Windows Release](https://github.com/ForwarderFactory/wii-banner-renderer/actions/workflows/windows.yml/badge.svg)](https://github.com/ForwarderFactory/wii-banner-renderer/actions/workflows/windows.yml)

[Showcase](https://www.youtube.com/watch?v=_UVSLDDvSd0)
[Web version](https://forwarderfactory.com/banner-renderer/)

**Note: Experimental, no support.**

This program allows you to render a Wii banner to a video file. 
It is based on the work of the Wii Banner Player team. 

The program is compatible with Windows, macOS and Linux. Do however note that macOS support is questionable at best, given that Apple no longer supports OpenGL and have deprecated the APIs. However, they still seem to be functional.

For Mac users, and everyone else, really, please check out the [web version](https://forwarderfactory.com/banner-renderer/).

## Usage

Call the program using the path to a *.wad*, *00000000.app* or *opening.bnr* as a parameter. It should generate a file in your working directory
You can pass in multiple files as well. The output file(s) will bear the name of the input file, with a different file extension, .mp4 and .wav.
Run it with no parameters for a list of parameters.

## Dependencies

- GLEW
- OpenGL
- OpenSSL
- EGL (Linux only)

## Prebuilt binaries

We have a GitHub Action for automatically building a Windows binary from the latest commit.
Download the latest artifact generated by it. If you use Linux, build it yourself.

## Building (Windows)

1. Install MSYS MINGW and set up an environment
2. Install dependencies
3. mkdir -p build
4. cd build
5. cmake ..
6. cmake --build .

## Building (macOS/Linux)

1. Install dependencies
2. mkdir -p build
3. cd build
4. cmake ..
5. cmake --build .

## Known bugs

- Text rendering is broken (or rather, not implemented fully)
- Animations don't quite work
- In some cases you might get an unplayable video file on some banners, cause is unknown.
