# wii-banner-renderer (libwb, wbr, wbp)

[![Build Windows Release](https://github.com/ForwarderFactory/wii-banner-renderer/actions/workflows/windows.yml/badge.svg)](https://github.com/ForwarderFactory/wii-banner-renderer/actions/workflows/windows.yml)

[Showcase](https://www.youtube.com/watch?v=_UVSLDDvSd0)
[Web version](https://forwarderfactory.com/banner-renderer/)

This program allows you to render a Wii banner to a video file. 
It is based on the work of the Wii Banner Player team, with some code taken
from WiiFlow and USB Loader GX.

The project consists of two parts:

- libwb (required)
  - C++ library which exposes almost all the banner handling. This, long term, should be cross-platform but that's not the case as of now.
- wbr
  - CLI utility which renders a banner to a video file using FFmpeg. Runs on Windows, macOS and Linux.
- wbp
  - Banner player, independent of wbr, which allows you to preview and view a ton of channels in real time.

The program is compatible with Windows, macOS and Linux.
Do however note that macOS support is questionable at best, given that Apple no longer supports OpenGL 
and have deprecated the APIs. However, they still seem to be functional.

## Usage (CLI)

Call the program using the path to a *.wad*, *00000000.app* or *opening.bnr* as a parameter. It should generate a file in your working directory
You can pass in multiple files as well. The output file(s) will bear the name of the input file, with a different file extension, .mp4 and .wav.
Run it with no parameters for a list of parameters.

If you would like debugging information, set WBR_DEBUG=1 in your environment, or run the program with
the -log parameter.

Some banners use the Wii's shared bitmap fonts. Pass the shared content archive
that contains `wbf1.brfna` and `wbf2.brfna` with
`--font-archive <path>`, or set `WII_FONT_ARCHIVE`. The content filename is not
fixed, so identify it by those files rather than assuming a particular `.app`
number.

You can also place `00000003.app` and `00000011.app` from `shared1` in the working directory of the program. 
You can obtain these files easily by installing the Wii System Menu in Dolphin, navigating to the virtual NAND 
and copying them. These are not guaranteed to work in all cases, but I haven't yet come across any cases where
doing this is not possible.

## Usage

Run the GUI application and select your channels using the + button. You can then use your mouse
or arrow keys to select channels to view.

If you would like debugging information, set WBP_DEBUG=1 in your environment.

## Dependencies

- GLEW
- OpenGL (preinstalled on most systems, including macOS)
- EGL (only needed on Linux)
- FFmpeg (optional if not building wbr)
- SDL3 (optional if not building wbp, downloaded and compiled automatically if not found)
- WolfSSL (always downloaded and compiled)

## Prebuilt binaries

We have a GitHub Action for automatically building a Windows binary from the latest commit.
Download the latest artifact generated by it. If you use macOS or Linux, build it yourself.

## Building (Windows)

1. Install MSYS MINGW and set up an environment
2. Install dependencies
3. mkdir -p build
4. cd build
5. cmake ..
6. cmake --build .

## Building (macOS/Linux)

1. Install dependencies
2. mkdir -p build
3. cd build
4. cmake ..
5. cmake --build .
